# Zuccä Caffè — Landing Page Concept

Conceito independente de landing page desenvolvido para apresentar a experiência da **Zuccä Caffè**, cafeteria localizada no bairro Assunção, em São Bernardo do Campo — SP.

> Este projeto é uma proposta visual independente e não representa, até o momento, um site oficial da Zuccä Caffè. As informações utilizadas foram obtidas de fontes públicas e devem ser confirmadas pelo estabelecimento antes de uma publicação oficial.

## Sobre o projeto

A página foi criada para reunir, em um único endereço, as principais informações da cafeteria e facilitar o contato de potenciais clientes.

O projeto destaca:

- proposta e identidade da cafeteria;
- cafés, brunch, lanches e ambiente pet friendly;
- avaliação pública no Google Maps;
- endereço e rota pelo Google Maps;
- contato por WhatsApp e telefone;
- perfil oficial no Instagram;
- experiência responsiva para celulares, tablets e computadores.

## Recursos da página

- layout responsivo;
- navegação fixa e menu para dispositivos móveis;
- animações suaves durante a rolagem;
- indicadores de navegação e progresso;
- seção de diferenciais;
- apresentação visual de produtos e ambiente;
- perguntas frequentes em formato de acordeão;
- botões de conversão para WhatsApp, Instagram e Google Maps;
- cuidados básicos de acessibilidade;
- metadados para mecanismos de busca e compartilhamento social.

## Como visualizar

Abra o arquivo `index.html` em um navegador. Nenhuma instalação ou compilação é necessária.

Para testar por meio de um servidor local:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Publicação no GitHub Pages

1. Envie o conteúdo deste projeto para a branch `main`.
2. Acesse **Settings → Pages** no repositório.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a geração do endereço público.

## Personalizações previstas

Antes de transformar o conceito em um site oficial, recomenda-se validar com a Zuccä Caffè:

- logotipo e identidade visual oficiais;
- cardápio e nomes dos produtos;
- horários completos de funcionamento;
- fotos autorizadas pelo estabelecimento;
- número oficial do WhatsApp;
- textos institucionais e promoções;
- domínio próprio e política de privacidade, se necessária.

## Créditos e direitos

O nome **Zuccä Caffè**, sua identidade e as imagens do estabelecimento pertencem aos respectivos titulares. Este repositório foi criado exclusivamente como demonstração de uma proposta de desenvolvimento web.
